# 0.8.0 (8) · 动作计时、双侧计组、素材包与Watch提醒

2026-11-26工作区，按用户要求开发并保留源码，未提交、推送或触发Actions。独立Watch App由用户明确排除本轮范围。

## 动作计时与两侧

- 编辑动作 → 预设值，或训练中 → 调整本组设置，可选择按时长训练、每组/每侧目标秒数，以及“一次完成一组 / 两侧完成才算一组”。替代项也有自己的预设。
- 平板支撑等49项目录动作提供可调整的计时默认值；33项明确分侧变式提供两侧完成方式。侧平板默认每侧40秒，平板默认每组40秒；这只是界面起点，不是个体训练处方。交替行走等不一律拆侧。数据由scripts/exercise_execution_defaults.json维护，生成步骤时同步目录，避免重新导入素材后丢字段。
- 开始计时后使用AlarmKit系统提醒；通知降级也支持动作计时，但受静音、专注模式及通知设置影响。UI倒计时不驱动提醒或自动计组；前台轮询到时也不取消系统动作提醒，保留到用户停止提醒或确认完成。
- 40秒/侧示例：开始第1侧 → 到时提醒 → 手动确认换侧 → 开始第2侧 → 到时提醒 → 手动确认整组。第一侧不增加整组、不开始组间休息；第二侧完成后才执行组间或动作间休息。左右先后自行决定，不假设检测出左右。
- 支持暂停、继续和重置当前侧计时；重置第二侧保留第一侧确认。系统停止提醒仅标记“计时结束”，不确认侧或组。训练页、锁屏训练卡片与灵动岛均支持开始/暂停/继续和确认，提醒与旧按钮使用各自ID防止重放。
- 倒计时到0且系统提醒有注册记录，或系统报告提醒正在响铃后，才能手动确认当前计时侧。未开始、提前点击、提醒注册失败都不计进度。失败可重试/重置；不能把一个没有注册的倒计时当作已完成。
- 双侧组或动作计时进行中锁定设置、替代项和重排；完成整组后可调整。提前结束或跳过时取消提醒并放弃未完成侧，半组不计为历史整组。活动快照保存1/2侧进度，App重启恢复不重复注册系统计时。
- 完成整组时保存目标时长和侧数；目标不冒充实际有效保持时长。计时/次数及单/双侧分别匹配历史口径，不自动混用；对比页支持计时完成组。

旧计划已有prescription时不暗中改写；可在预设或本组设置手动启用。无预设且有有效catalogID的动作，在新训练中使用目录默认值；仅名称匹配的自定义动作保留旧负重口径，可手动启用计时/双侧或从动作库明确关联。旧活动训练继续其原快照。

## 独立素材包

- 默认轻量IPA不含动作PNG。首次从“设置 → 动作素材管理”导入GymRest-Official.gymrestmedia，之后离线读取Application Support/MediaPacks；不放入Caches，不随完整训练备份内嵌，也不自动放入iCloud设备备份。可单独导出，卸载后重新导入。
- 构建支持MEDIA_MODE=external/bundled及MEDIA_SEED_POLICY=preserve/updateOfficial。含包模式首次启动安装，默认保留已有官方包；updateOfficial只升级更高且兼容的官方revision，保留用户包和旧版。轻量模式没有种子包，覆盖策略不会凭空提供图片。
- 同Bundle ID且保留数据容器的正常覆盖安装复用素材。升级到轻量版时不能读取旧版已经被系统替换的Bundle：首次需手动导入，或先安装含包过渡版。卸载、清除数据、换Bundle ID及特定侧载工具的重装行为不保证保留。
- 官方运行包包括775张获准展示原PNG、306项明确映射、作者/来源/许可及审核清单。取消展示的图片不进运行包；另有GymRest-Media-Sources.zip保存全部912张原图及完整来源，供追溯，不是可导入运行包。
- 首版为标准ZIP容器的ZIP_STORED子集，扩展名.gymrestmedia。PNG已压缩，容器不再压缩；因此无需第三方ZIP依赖，也没有解压压缩炸弹入口。仅接受单卷、无注释/附加字段/加密/链接/ZIP64的有限格式。可用仓库生成工具制作；普通压缩ZIP会被明确拒绝。
- 导入前检查大小、中央/本地目录一致性、路径、重复项、重叠、全部SHA256、图片真实PNG类型与可解码尺寸、许可和来源。文件≤100MiB，条目≤3000，单资源≤10MiB，PNG≤4096×4096，manifest≤2MiB。哈希是完整性检查，不是发行方签名认证；目前手动从可信发布文件导入，不后台自动更新。
- 先临时校验并预览，安装新版本目录，最后原子切换索引；失败保留旧索引和旧包。清理未激活暂存区，版本支持回滚、启用/停用和移除。已装同revision不同内容拒绝，降级需明确选择；旧版本占用保留至移除整个包。
- 稳定catalogID优先。第三方条目无有效ID时可用唯一名称匹配，并在预览中手动选择目标；歧义/未知保留未匹配，不创建或改写动作。一个包不允许多个条目映射同一动作。后导入的自选包优先，官方升级保持原顺序；pending映射可以明确撤回图片，不能从旧后备图绕过审核。
- 本地匹配选择随包版本索引保存并随回滚切换；导出有手动映射的包时生成独立user.mapped派生包，写入原包来源与修改记录，避免同一官方版本内容被静默改写。图片字节不修改。包切换刷新图片缓存和放大页。
- 训练或恢复异常期间不允许修改素材；完整备份页面明确提示素材需单独导出。缺包提示与无准确配图提示区分，器材图片仍不展示。

## Watch开训前提醒

设置中“开始训练前提醒开启Watch训练”默认关闭。开启后，新训练开始前可选择“已在手表开启，开始训练”“本次不记录，继续”或取消。真正确认之后才创建GymRest训练和开始时间；继续/恢复原训练不重复提示。

文案明确这是手动确认。没有读取系统体能训练实时状态，没有增加健康写入或Watch目标；当前公开镜像接口只用于自有伴侣App，不能用查不到已保存HKWorkout推断用户没开训练。

## 格式与构建

- 计划导入兼容version1–4；含目标计时或双侧的计划导出version4，其余按内容保留1/2/3。新增prescription.durationSeconds（1–86400，计时时repetitions为空）和sideCount（1或2，旧数据缺省1）。示例examples/timed-bilateral-v4.json。
- 完整备份导出GymRestBackup v2，继续读取v1；包含新目标/侧数和Watch提醒偏好，不含素材大图、活动训练和系统计时。
- macOS：`MEDIA_MODE=external MEDIA_SEED_POLICY=preserve bash scripts/ci.sh`；需要含包可改为bundled，升级种子可改为updateOfficial。手动工程生成前执行scripts/prepare_icon.sh与scripts/prepare_media_project.py，再对.gymrest-media.yml运行XcodeGen；HealthKit在此生成规格上叠加。
- Actions增加两个手动选项；默认push构建为轻量+保留。输出IPA、独立素材包、来源归档。生产IPA禁止散落wg-/ek- PNG，912张图片只进入测试bundle的fixture与单独来源归档，不进轻量IPA。
