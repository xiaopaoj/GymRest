# 分帧清晰度与重复姿势复核 · 2026-11-26

此前的一般视觉核对侧重动作、器材和变式匹配，对粗糊重绘和重复姿势筛选不足。本次从全部当前展示的WorkoutGuide帧中计算归一化轮廓相似度，人工查看排名前60对候选及用户指出的窄距杠铃卧推。相似度只用于筛查，不直接决定删除；不同关节位置不因器材背景相同而自动剔除。

本轮调整39组，取消展示47帧；所有912张来源原图仍保留原字节、哈希及署名。306项动作、280项配图动作不变；展示帧从822降为775。只调整图片展示选择，不删除动作、计划或训练记录。没有修改图片像素，也没有放大锐化生成教学素材。

窄距杠铃卧推保留原第1、3帧，去掉粗糊且重复伸臂姿势的第2帧。单张静态示意不代表完整运动过程；全部保持关闭自动播放。
