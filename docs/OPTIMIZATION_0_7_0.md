## 导入诊断与动作匹配

- 文件选择兼容JSON、普通文本与通用数据类型；内容仍完整解码校验，计划最大10MB。
- 接受UTF-8 BOM、首尾空白和单个完整的Markdown JSON代码块；不从任意说明文字中截取JSON，不放宽数据范围。
- 解码错误显示JSON路径；数据校验显示训练日、动作和具体字段/组号。UUID及枚举等仍按原规则验证；未知catalogID不阻止作为自定义动作导入。
- 预览中提供动作关联页：区分标识匹配、唯一名称匹配、未匹配；显示原文件训练参数和候选的器材/负重口径，可手动查看动作图片后选择。批量仅应用唯一的准确名称/别名匹配，不做模糊替换。
- 匹配只调整关联标识及可选的动作库名称；UUID、组数、休息、负重预设与替代结构保留。器材变化后需自行调整原负重口径。
- 应用匹配后重新冻结覆盖预览；确认期间本地目标变更的旧保护仍执行。取消匹配页不修改预览或数据库。

## 完整备份与合并恢复

设置新增“完整备份与恢复”，保存计划/训练日、全部训练记录、实际逐组重量/次数、原始快照、健康运动引用及四项用户设置。图片随App提供，不复制到备份；进行中的训练及系统提醒不在备份内。

备份有独立format=GymRestBackup、version=1，日期采用毫秒时间戳；计划JSON仍为version1/2/3。两种文件入口可识别并提示正确页面。备份最大50MB，导出前也执行完整校验，避免生成无法恢复的文件。

恢复先展示日期与数量，确认后按稳定ID合并：本地已有ID保留，仅补充缺失内容；重复恢复不重复创建，不删除本地历史。设置恢复可选且默认关闭。存在当前训练或未保存编辑时阻止恢复。所有插入及可选设置更新一次save提交，失败回滚并恢复设置缓存；不注册历史闹钟或向HealthKit写入数据。

这是合并恢复，不是将整个数据库覆盖回旧日期：同ID的本地新编辑保留。损坏备份整份拒绝，不部分导入。

## 动作与训练界面

- 305项动作均有中文显示名，保留源英文名称/别名用于检索。译名表scripts/workout_guide_zh.tsv纳入可重现导入脚本，906张原图及来源哈希保持不变。
- 训练首屏先展示当前组重量/次数及预填来源，再展示可折叠图片；图片可单独放大查看。
- 固定底部操作区显示正在训练/组间休息/动作间休息/暂停、累计组数、下一动作与可用的下一动作预设，完成本组/休息控制无需滚动到底部。
- 值来源区分计划预设、包含历史预填、本次手动调整与沿用上一组；替代切换及剩余重排同时对齐来源。
- 沿用上一组仅取本动作且负重口径、单位、器械备注匹配的已完成组，仍经过交互token校验；不改写过去记录，不自动换算负重。
- 锁屏卡片增加已确认的全程累计组数及准备/休息状态，动作名可显示两行；旧状态数据缺少新字段仍兼容。仍复用原有持久化和重复操作保护。
- 历史增加“按动作查看重量与次数变化”，按实际动作标识/规范名称、单位、负重口径和器械备注分别展示最近10次记录与逐组值。旧版未记录值不推测，辅助重量变化不被解释为力量进步。
