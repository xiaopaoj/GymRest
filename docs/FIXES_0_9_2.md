# 0.9.2 (11) 修复记录（2026-11-27）

## 秒数动作没有倒计时

复核用户此前的五分化v3文件发现：平板支撑以repetitions:60存储，equipmentNote为“按秒计：60秒/组”；侧平板以repetitions:40、备注“每侧40秒”存储。它们没有durationSeconds，因此只被计为次数。

新增保守兼容：明确“按秒计”“每组N秒”“每侧N秒”“N秒/组”等单一计时备注，且数字与旧repetitions一致或旧次数为空时，转为durationSeconds；每侧秒数同时转为两侧完成一组。主动作、替代动作、旧本地计划升级和v3导入均适用；现有活动训练通过当前组读值兼容，不改写原有已完成历史。新导出会按已有规则使用v4。只写休息时间、普通次数、多个时间范围、互相冲突的数字不自动转换；明确设置的durationSeconds始终优先。

无预设的名称匹配计时动作可补目录目标时长，不改变旧负重口径/单位；明确设置次数的动作不强制改成计时。编辑器关闭计时后移除匹配的旧计时片段，保留其他器械备注，避免下次再次被当作秒数。

仍需手动点击“开始计时”，到时由系统提醒并手动确认完成，不自动计组。计时提醒的签名/系统权限要求保持原有逻辑。

## 返回首页后标签被遮挡

原全局训练条通过safeAreaInset附在整个TabView底部，与iOS26标签栏布局冲突。改为在四个标签的NavigationStack内容区分别预留训练条空间，保留系统TabView对标签栏的布局管理，不使用固定底部偏移值。小屏、辅助功能大字体、返回首页/切换标签仍待模拟器与真机截图验收。

## 健康授权按钮完全无反应

不能在无日志的情况下确认具体系统/签名原因。改为显式反馈：授权请求中、查询中、返回0条/有样本、失败原因及查询时间；训练tips关闭时设置页仍单独显示结果。Form内按钮使用borderless独立点击；非HealthKit构建不再只有无法点击的静默禁用按钮，而由读取请求给出已有构建未启用提示。

增加授权请求90秒、查询20秒的软件等待上限；超时显示可重试原因并解除busy，迟到回调不能覆盖新状态。取消时同样结束等待。此上限不会替用户关闭系统权限页面，也不会更改系统授权状态。已有允许或拒绝记录时系统可能不再弹授权页，页面明确提示去系统健康App查看GymRest的锻炼分钟数权限；空样本仍无法区分未授权或未同步。

审查后补充修正：旧秒数仅匹配完整计时片段，混有次数、额外时长或冲突侧数的备注保留原样。近期健康样本查询在取消或超时时停止底层 HealthKit 查询，回调只结算一次。开始重试前会清理仍在运行的旧查询。设置页仅由按钮发起读取，自动轮询限于训练页。
