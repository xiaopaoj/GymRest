## 名称匹配与训练界面

训练页先使用有效catalogID；缺失或失效时，以动作中英文名称、别名执行去空格/标点、大小写和全半角规范化后的精确匹配。同名候选不唯一、只命中部分字符串或未知变式时不猜测。素材匹配不改变实际负重、动作ID或旧训练快照；仅这四个已校对动作的明确名称别名会在导入预览前和计划保存时统一为规范名。

当前动作图片直接显示在训练页名称下；更换动作/替代项会重新选择图片。可手动切三帧，或选择分帧播放；默认静态，尊重减少动态效果，离开停止。分帧播放明确标为姿势示意，不冒充插帧视频，也不驱动训练组或休息计时。原图为透明白色线稿，使用深色画布支持深浅色界面。

动作详情使用相同组件。器材图片及“图片待补充”提示均移除，仅保留所需器材文字。设置和动作详情均提供素材许可入口。
